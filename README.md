# Курсовые работы по уголовному праву (БЮИ МВД России)

Систематизированный репозиторий материалов, исходных текстов, скачанных первоисточников, инструментов сборки/аудита и готовых курсовых работ по требованиям приказа БЮИ МВД России от 16.12.2022 № 1014.

## Структура репозитория

- `docs/` — нормативная и методическая база:
  - `polozhenie_bui_1014.docx` — Положение о курсовой работе БЮИ МВД России (приказ от 16.12.2022 № 1014);
  - `ИИ_паттерны_и_антиплагиат.md` — расширенное руководство по устранению ИИ-паттернов (156 правил), проверке юридической достоверности, антиплагиату и стандарту вёрстки;
  - `ПЕРЕПИСКА.md` — история уточнённых требований из прошлых проходов;
  - `sample_kursovaya_ura.txt` — образец структуры курсовой работы («Уголовный закон»).
- `pipeline/` — универсальный автономный конвейер сборки и проверки:
  - `build_kursovaya.py` — двухпроходная сборка `.docx` и `.pdf` из `src/01..05.txt`;
  - `engine.py`, `render_pdf.py`, `doc_utils.py`, `mk_parser.py` — генератор DOCX по шаблону `templates/ref.docx` и точный PDF-рендер (PyMuPDF + `fonts/LiberationSerif-*.ttf`);
  - `audit_metrics.py` — автоматический аудит ритма (CV, короткие фразы, серии равной длины), повторов зачинов, ИИ-клише, длинных тире, сносок, заголовков и порядка библиографии;
  - `audit_ngrams.py` — проверка пересечений по 8-граммам против скачанных источников и против всех прошлых работ;
  - `requirements.txt` — зависимости для сборки (`pymupdf`, `python-docx`, `beautifulsoup4`, `lxml`, `xlrd`).
- `shared_sources/` — общие базовые материалы (статистика Судебного департамента `k3_2024.xls`, `k3_2025.xls`, `k3-1-2025.xls`, учебник ТГУ по Особенной части УК РФ).
- `works/` — выполненные курсовые работы (`.docx`, `.pdf`, исходники, скачанные источники, отчёты проверки):
  - `01_iznasilovanie_131/` — «Уголовно-правовая характеристика изнасилования (ст. 131 УК РФ)»
  - `02_prostitutsiya_240/` — «Вовлечение в занятие проституцией (ст. 240 УК РФ)»
  - `03_obekt_prestupleniya/` — «Объект преступления: понятие, значение, виды»
  - `04_ugolovnyy_zakon/` — «Уголовный закон: понятие, значение, задачи и принципы»
  - `05_statya_228/` — «Уголовно-правовая характеристика преступления, предусмотренного ст. 228 УК РФ»
  - `06_statya_228_1/` — «Уголовно-правовая характеристика преступления, предусмотренного ст. 228.1 УК РФ»
  - `07_terroristicheskiy_akt_205/` — «Уголовно-правовая характеристика террористического акта (ст. 205 УК РФ)»

## Основные команды конвейера

```bash
# 1. Аудит текста на ИИ-паттерны, ритм, сноски и структуру (работает на чистом stdlib)
python3 pipeline/audit_metrics.py works/<папка_работы>/src

# 2. Проверка на 8-граммные заимствования против источников и всех прошлых работ
python3 pipeline/audit_ngrams.py \
  --src works/<папка_работы>/src \
  --sources works/<папка_работы>/sources \
  --compare-works works

# 3. Сборка DOCX + PDF (требует установки зависимостей: pip install -r pipeline/requirements.txt)
python3 pipeline/build_kursovaya.py \
  --work-dir works/<папка_работы> \
  --title "Тема курсовой|(подзаголовок при наличии)" \
  --out-name "Курсовая_<тема>_БЮИ" \
  --keywords "уголовное право; ..."
```
